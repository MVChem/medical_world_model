\section{Evaluation Details}
\label{app:protocol}

\subsection{Inputs, cohorts, and matched training}

The executable protocol has five future tasks in
Table~\ref{main-tab:future_prediction} and three current tasks in
Table~\ref{main-tab:downstream_tasks}. The current comparison includes a
raw-input task decoder, native Qwen3.5-9B without project training, and
Qwen3.5-9B-based MedWorld with eight additional slot conditions. Other methods
listed in the main tables remain separate planned experiments. Missing results
are not imputed from earlier protocols.

The raw baseline learns image patches, optional report embeddings, and its task
readouts from scratch. It constructs no Qwen, V-JEPA, world predictor, EMA target,
or visual slot consistency branch. MedWorld supplies the same raw task inputs
and adds eight slots from its separate Qwen/V-JEPA state encoder. Current tasks
use the source slots; future tasks use the world predictor's forecast slots.
Both trained arms start from identical task-decoder and readout weights and
receive equal optimizer updates and per-task sample counts. Only MedWorld uses
temporal latent prediction and visual slot consistency supervision.

Each update selects one task from a fixed eight-task cycle. MedWorld also uses a
temporal pair batch with signed elapsed hours and detached EMA target slots;
the baseline has no temporal batch. Temporal representation training uses the
paired selection in \texttt{medworld\_0923}. Medication records contributed to
that cohort's selection but are not model inputs. The current experiment uses
a shared approximate one-day training budget, calibrated over three full task
cycles per arm; both formal arms restart from the original initialization and
finish the same number of complete cycles. Evaluation takes additional time.

Future VQA selects the closest eligible earlier frontal examination for each
official target image from the full CXR timeline. Future report generation
selects the closest eligible source among the forward pairs in
\texttt{medworld\_0923}. Neither selection examines target labels. Future VQA
takes a single categorical answer from the official local question annotations.
Its longitudinal split follows existing global patient holdouts across all
original annotation partitions, rather than the published current-image test
partition. Annotations from future test patients are absent from every training
task; original annotation IDs and partitions are retained. Progression requires an explicit comparison tied to the
exact previous and current image IDs, anatomical region, and finding. All
Chest ImaGenome human gold patients already belong to the shared test holdouts;
they remain test-only. Source-anchored report-derived silver comparisons on
other patients supply training and validation labels. Conflicting or mixed
comparison directions are excluded before model inference. Equality of binary
finding labels does not establish stability.

Patient holdouts are shared across current tasks, temporal learning, and future
tasks. Clinical outcome cohorts start from the full linked source-examination
inventory and do not require a later radiograph or medication record. An
examination must belong to one unambiguous recorded encounter, including its
linked emergency-department interval where available. Original manifests,
exclusion counts, label support, and patient/cohort hashes are retained with
the prepared data and each run.

Future inference receives only the source image, source report, and prescribed
request. All methods receive the same source report prefix of at most 383 UTF-8
bytes. Future VQA and progression additionally receive the task question and
actual requested positive interval. Mortality always requests 30 days;
remaining length of stay uses a fixed 24-hour latent readout request, never the
observed outcome duration. Target images, reports, labels, discharge times, and
death records do not enter the prediction function. The retrospective protocol
assumes the source report is available at the examination.

\subsection{Table 1: future prediction}

\paragraph{Future VQA accuracy.}
Each question has one reference answer from the fixed official categorical
vocabulary. Accuracy counts correct normalized answers over all fixed eligible
questions. Invalid outputs count as incorrect. Native Qwen scores a pinned
single-token option codebook; the supervised arms use a categorical readout.

\paragraph{Progression balanced accuracy.}
Human test annotations distinguish improved, stable, and worsened changes for
an explicitly requested region and finding. The primary score is the mean of
the three class recalls over all eligible region--finding examples. All three
classes must have test support. Per-class and per-finding support accompany the
primary score; an invalid direction remains an error in its reference class.

\paragraph{Future report RadGraph F1.}
We use the official RadGraph-XL partial entity/relation F1, averaged over the
fixed full observed target reports. Scorer source, model, tokenizer, and runtime
assets are pinned by hashes. All generators have the same 2,047-byte output
budget plus a decoder termination token. Generation is greedy. Original target
reports are retained in full for scoring even when a training target exceeds
the decoder's byte budget. No lexical similarity substitute is used.

\paragraph{Thirty-day mortality AUROC.}
The prediction target is death within 30 days after the source examination,
not mortality measured from admission. Exact recorded in-hospital death times
take precedence over date-only patient death records. Date-only deaths whose
precision overlaps the start or end boundary are excluded. Negative labels
require known survival beyond the horizon or sufficient death ascertainment
under the source release's one-year post-discharge follow-up window. Censored
or contradictory records are excluded before inference. AUROC uses continuous
risk predictions and requires both classes; repeated source examinations
remain grouped by patient in all splits.

\paragraph{Remaining length-of-stay MAE.}
The reference is the linked encounter's discharge time minus source acquisition
time, in days. Discharge by death is included. Trained readouts predict a
nonnegative duration; MAE is the mean absolute error in days. Native Qwen uses
the probability-weighted expectation of a fixed day grid
$\{0,0.5,1,2,3,5,7,10,14,21,30,60,90,180,365\}$; this grid is fixed independently
of evaluation labels. The fixed 24-hour latent request does not redefine the
remaining-stay outcome as a 24-hour endpoint.

Table 1 reports the first four scores as percentages and length-of-stay MAE in
days. Missing prediction records or invalid numeric outputs make an evaluation
incomplete rather than changing the reference denominator. Outcome scores
characterize the linked CXR population and its ascertainment rules.

\subsection{Table 2: current downstream tasks}

Current classification, segmentation, and VQA withhold the same-examination
report, including from the slots encoder. VQA additionally receives its question.
Classification uses 13 report-derived finding/device labels, masks uncertain and
missing references, and reports macro AUROC and non-interpolated average
precision over findings with both positive and negative test support. Native
Qwen uses fixed Yes/No likelihood scores for these findings.

Current VQA uses the official local answer vocabulary and JSON answer arrays.
After lowercasing and trimming surrounding whitespace, exact answer-set match
and pooled micro F1 are computed on the same references. Malformed outputs count
as errors. The prescribed comparison selects 100 Verify, 100 Choose, and 100
Query questions with seed 42; IDs and reference hashes bind every method to this
same 300-question subset. This is not a full-test VQA score.

Segmentation uses human-reviewed masks only: the 200-image MIMIC heart/lung
collection, UCSF-ALPTDG and MU-Glioma-Post MRI, and the external Montgomery lung
test. No CXAS pseudo masks are used. The shared decoder predicts six channels:
lungs, heart, NETC, SNFH, ET, and RC. Only annotated channels and spatial regions
contribute to loss and metrics. Predictions threshold sigmoid outputs at 0.5;
an empty prediction against an empty reference scores one. MRI slice confusion
counts are summed within each volume before channel and volume averaging.
Per-dataset mean Dice and IoU are reported for both trained arms. The main table
equally averages the three internal datasets, while Montgomery is reported
separately. Native Qwen has no segmentation head and receives N/A.

Full table export requires completed checkpoints with matching initialization,
update counts, per-task sample counts, data fingerprints, test IDs, and reference
hashes. Only trained parameters and compact EMA state are saved; frozen
pretrained backbones are referenced by their original asset hashes. Optimizer
state is not retained, and these checkpoints support evaluation rather than
exact training continuation. Earlier metric formats are not accepted by the
current exporters.
