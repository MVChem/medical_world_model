Medical world models aim to anticipate how a patient's condition evolves. Realizing this goal requires a predictive state that connects clinical meaning with visual evidence. We introduce \method{}, a medical world model that learns the dynamics of multimodal patient states through joint-embedding prediction. Images and reports define a shared latent state space, and actual follow-ups supervise its temporal evolution. A multi-depth encoder constructs compact states from complementary vision--language and visual slots. Clinical and spatial task supervision first establishes the content of these states; a horizon-conditioned world model then learns to predict the state encoded from a real follow-up image--report pair. This JEPA objective operates directly in the multimodal state space and updates the current-state encoder together with the dynamics predictor. Future observations enter only the target branch. The resulting model provides two inference pathways: predicted states support future finding and report readouts, while current states support clinical understanding and image-conditioned spatial tasks.
