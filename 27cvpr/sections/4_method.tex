\paragraph{Overview.}
\method{} couples a multimodal state encoder with a horizon-conditioned latent world model (\cref{fig:medworld_jepa_overview}). At both time points, four vision--language slots and four visual slots form the state. Task decoders jointly supervise its construction, with direct image input for segmentation and super-resolution. The world model predicts future slots from the current state and horizon while jointly adapting the state encoder. For forecasting, a Qwen language decoder reads the predicted slots and a fixed report-generation prompt; the source observation and time interval reach it through the predicted state. The current implementation uses Qwen3.5-0.8B and a frozen V-JEPA encoder. Evaluation of this unified implementation remains pending; the completed Table~\ref{tab:future_prediction} adaptations are legacy prototypes with a different readout.

\subsection{State Representation}
\label{sec:state_representation}

\paragraph{Shared multimodal state encoding.}
Current and follow-up observations share an encoding design with $K=8$ slots of width $d=1024$. We use image--report pairs for longitudinal prediction; image-based downstream evaluation withholds the same-exam report. State construction precedes both the task query and horizon. The two slot groups retain distinct feature sources throughout their readout and alignment.

\paragraph{Visual and vision--language feature sources.}
A frozen JEPA encoder $f_\theta$ provides spatial features~\citep{assran2023ijepa,bardes2024vjepa,murlabadia2026vjepa21}, mapped by a trainable visual adapter $a_\rho$ into the VLM embedding space of width $d_L$:
\begin{equation}
    \begin{aligned}
        D_\tau&=f_\theta(X_\tau)\in\mathbb R^{N_D\times d_D},\\
        V_\tau&=a_\rho(D_\tau)\in\mathbb R^{N_V\times d_L}.
    \end{aligned}
    \label{eq:visual_evidence}
\end{equation}
The JEPA features are pooled to an $8\times8$ grid and mapped to 64 language-width tokens with learned positional embeddings. The VLM fuses these tokens with available text embeddings, yielding layerwise hidden states $H_\tau^{(\ell)}$. In parallel, the VLM's own vision encoder processes $X_\tau$ to produce visual features $F_\tau^{(k)}$ before language fusion. These native visual features supply the last four slots; the JEPA-to-VLM adapter and the slot readouts below have separate roles.

\paragraph{Multi-scale slot construction.}
As shown in Figure~\ref{fig:task_supervised_slots}, we select four depths from each source: one early layer, two intermediate layers, and the final layer. Let $\ell_j$ and $k_j$, $j=1,\ldots,4$, index the selected fusion and visual layers. Multi-scale refers to this hierarchy of representation depths. The lightweight adapter aggregates each selected feature sequence and projects it to one $d$-dimensional slot using source-specific learned readouts $r_j^{\mathrm{f}}$ and $r_j^{\mathrm{v}}$:
\begin{equation}
    \begin{aligned}
        s_{\tau,j}^{\mathrm{f}}&=r_j^{\mathrm{f}}(H_\tau^{(\ell_j)})\in\mathbb R^d,\\
        s_{\tau,j}^{\mathrm{v}}&=r_j^{\mathrm{v}}(F_\tau^{(k_j)})\in\mathbb R^d,\\
        S_\tau&=E_\eta(O_\tau)=[S_\tau^{\mathrm{f}};S_\tau^{\mathrm{v}}]
        \in\mathbb R^{8\times d}.
    \end{aligned}
    \label{eq:vlm_state}
\end{equation}
For Qwen3.5-0.8B, the selected language layers are 6, 12, 18, and 24, and the vision layers are 3, 6, 9, and 12 (one-based). Four learned query tokens follow the visual prefix and observation text; fusion readout $j$ projects query token $j$ at language layer $\ell_j$. Each visual readout projects its layer's patch tokens, applies learned-query attention pooling, and normalizes the pooled vector plus its query. Each group stacks its four slots in depth order: $S_\tau^{\mathrm{f}}=S_{\tau,1:4}$ and $S_\tau^{\mathrm{v}}=S_{\tau,5:8}$. Alignment gives them a common width while preserving their sources; visual readouts do not receive fused or report features. Slots vary with the observation, with no fixed assignment to diseases, organs, or image regions. All eight enter the world model without further pooling. The encoder parameters $\eta$ comprise the adapters, slot readouts, and selected VLM parameters.

\paragraph{Task-conditioned readout.}
Each task uses a decoder with parameters $\omega_q$ and, when needed, a query $Q_q$. Classification and report generation read all eight slots. The classification head uses finding-specific attention queries; the report decoder receives projected slots followed by a fixed task prompt. Segmentation reads the input image together with only the four visual slots:
\begin{equation}
    \widehat M_\tau=H_{\omega_{\mathrm{seg}}}(X_\tau,S_\tau^{\mathrm{v}},Q_{\mathrm{seg}}).
    \label{eq:segmentation_interface}
\end{equation}
Image-guided feature upsampling motivates this combination: FeatUp's guided variant~\citep{fu2024featup} lifts coarse backbone features to higher spatial resolution using image detail and multi-view consistency, while UPLiFT~\citep{walmer2026uplift} combines image guidance with local feature aggregation and multi-scale reconstruction supervision. We use this complementarity through hidden-state conditioning: the image branch retains spatially resolved local evidence, and $S_\tau^{\mathrm{v}}$ supplies visual context from multiple depths as the decoder constructs dense outputs. Task losses learn their interaction without imposing a one-to-one slot-to-pixel correspondence. An optional training-only visual consistency objective additionally supervises the visual slots, as described below.

Super-resolution likewise reads image pixels and four visual slots, both derived exclusively from the same low-resolution input:
\begin{equation}
    \begin{aligned}
        \widehat X^{\mathrm{HR}}&=H_{\omega_{\mathrm{SR}}}(X^{\mathrm{LR}},S^{\mathrm{v,LR}}),\\
        \mathcal L_{\mathrm{SR}}
        &=\frac{1}{N}\left\|\widehat X^{\mathrm{HR}}-X^{\mathrm{HR}}\right\|_F^2.
    \end{aligned}
    \label{eq:sr_loss}
\end{equation}
Here $S^{\mathrm{v,LR}}$ is obtained by applying the visual encoder and its four readouts to $X^{\mathrm{LR}}$. The HR image supplies supervision only. $N$ counts valid target pixels, excluding padding; prediction and target share an intensity scale. Neither spatial decoder reads $S^{\mathrm{f}}$. The unified training pipeline implements classification, report generation, segmentation, and super-resolution; VQA, instruction-based disease recognition, and phrase grounding remain outside this implementation.

\subsection{State Prediction}
\label{sec:state_prediction}

\paragraph{Horizon-conditioned latent dynamics.}
The latent world model takes the current state tokens and an embedding of the requested horizon, and predicts a state with the same token shape:
\begin{equation}
    \widehat S_{t,h}=P_\psi(S_t,h)\in\mathbb R^{K\times d}.
    \label{eq:state_transition}
\end{equation}
The predictor receives both slot groups, with no additional image or feature-map input. Latent prediction on pretrained features has precedent in DINO-WM~\citep{zhou2025dinowm}; our predictive space combines fusion and visual slots. Prediction is direct at $h$; multi-time-point records supply training pairs without requiring autoregressive rollout. Training uses the signed realized interval in hours, with both forward and reversed pairs. The predictor projects normalized slots to width 512 and adds slot positions and a time embedding before four Transformer layers. Its time features encode the sign and log-magnitude of the interval in days; a zero-initialized output projection adds a residual to the normalized input state. The encoder itself receives neither direction nor time interval.

\paragraph{Observed future states as targets.}
Let $E_{\bar\eta}$ denote the target instance of the same encoding design. The actual follow-up provides the target for latent prediction:
\begin{equation}
    \begin{aligned}
        S^*_{t^+}&=E_{\bar\eta}(O_{t^+})\in\mathbb R^{K\times d},\\
        \mathcal L_{\mathrm{future}}
        &=\ell_S\!\left(\widehat S_{t,h},\operatorname{sg}(S^*_{t^+})\right),
    \end{aligned}
    \label{eq:future_latent_loss}
\end{equation}
where $\operatorname{sg}$ stops target-branch gradients. The follow-up image supplies both feature pathways, and its report contributes to the fusion slots. This latent objective supervises the eight future slots, with no separate dense feature-map loss. Future observations and their modality indicators are not predictor inputs.

The fixed source and depth ordering establishes correspondence between predicted and target slots. We use elementwise mean squared distance after independently applying non-affine LayerNorm over each predicted and target slot's 1024 channels. Current spatial decoders also require the corresponding input image and therefore do not directly define dense future outputs.

\paragraph{Report forecasting from predicted states.}
Let $A_\gamma$ project the eight predicted slots to the Qwen language width, and let $Q_{\mathrm{report}}$ be a fixed report-generation prompt. The report decoder and finding head read the predicted state:
\begin{equation}
    \begin{aligned}
        \widehat R_{t,h}&=D_\omega\!\left(A_\gamma(\widehat S_{t,h}),Q_{\mathrm{report}}\right),\\
        \widehat p_{t,h}&=H_{\omega_{\mathrm{cls}}}(\widehat S_{t,h}).
    \end{aligned}
    \label{eq:augmented_forecast}
\end{equation}
Projected slots precede the fixed prompt in the language decoder's input sequence. The decoder has no direct source-image, source-report, or horizon input. Source evidence is encoded into $S_t$, and temporal conditioning is applied by $P_\psi$. The same report decoder and 13-finding classification head serve current-task learning; temporal supervision selects six finding outputs. Encoder and report decoder share immutable pretrained language weights but have independent LoRA parameters, initialized before joint training and trained through their respective losses. Target report tokens are used for causally masked teacher forcing, while target images and reports also supply the detached target state through $E_{\bar\eta}$.

\subsection{Single-Stage Joint Training}
\label{sec:training}

Single-time-point annotations supervise state content, while longitudinal pairs supervise its evolution. We optimize both in one continuous training run from pretrained JEPA and VLM weights. Every optimizer update combines a current-task batch with a temporal batch, jointly training the online state encoder, dynamics predictor, and active task heads.

\paragraph{Current-task supervision.}
Starting from pretrained JEPA and VLM weights, we jointly train the adapters, multi-scale slot readouts, task decoders, and selected VLM parameters using parameter-efficient adaptation~\citep{hu2022lora}; JEPA remains frozen. The current-task component cycles through classification, report generation, segmentation, and super-resolution, drawing each batch from its task-specific training pool. Each task contributes once every four optimizer updates, alongside temporal supervision at every update. The task objective is
\begin{equation}
    \mathcal L_{\mathrm{task}}
    =\frac{1}{4}\sum_{q\in\mathcal Q}
      \mathbb E_{i\sim\mathcal D_q}
      \left[\ell_q\!\left(\widehat y_i^{(q)},y_i^{(q)}\right)\right],
    \label{eq:task_loss}
\end{equation}
where $\mathcal Q$ contains the four implemented tasks and $\mathcal D_q$ is the corresponding training pool. Each prediction uses the task-specific slot subset and inputs defined above. Classification uses class-weighted binary cross-entropy with unknown and uncertain labels masked, report generation uses token cross-entropy, segmentation uses Dice and pixelwise binary cross-entropy, and SR uses \cref{eq:sr_loss}.

There is no stop-gradient between the task decoders and slot readouts. Task gradients flow through $S$ into the learned aggregation/projection modules and any adapted source layers, jointly with decoder updates. Classification and report generation supervise both slot groups; segmentation and SR directly supervise $S^{\mathrm{v}}$ and their image decoders. Thus training updates the shared parameters that produce observation-dependent slots, rather than treating each sample's slots as independent optimization variables. Current-task inputs withhold the same-exam report, including during report generation; segmentation and SR compute only the visual branch.

\paragraph{Optional visual slot spatial consistency.}
During segmentation and SR updates, an auxiliary reconstruction module maps the four visual slots to a spatial feature field without reading image pixels. A frozen, unadapted Qwen vision teacher supplies feature targets for the original input and two independently encoded deterministic crops. The reconstructed field undergoes matching spatial transformations and is compared with channel-normalized teacher features over valid image regions. The maintained training configuration adds this loss with weight 0.1; the base configuration disables it. For SR, both slot and teacher inputs derive exclusively from the LR image. This objective updates the visual-slot encoder and auxiliary reconstruction module whenever the current-task component is segmentation or SR; it is inactive during evaluation.

\paragraph{Joint objective.}
From the first update, we train $P_\psi$ on same-patient current--future observations, primarily MIMIC-CXR image--report pairs~\citep{johnson2019mimiccxr}, together with the current-task objective. Future latent, report, and finding losses update $P_\psi$ and the current-state construction modules, while report and finding losses also update their respective decoder and classification head; JEPA remains frozen. The expected joint objective is
\begin{equation}
    \begin{aligned}
    \mathcal L_{\mathrm{joint}}
    ={}&\lambda_S\mathcal L_{\mathrm{future}}
       +\lambda_R\mathcal L_{\mathrm{report}}\\
      &+\lambda_F\mathcal L_{\mathrm{finding}}
       +\mathcal L_{\mathrm{task}},
    \end{aligned}
    \label{eq:joint_loss}
\end{equation}
where the main losses are averaged over sampled directed pairs, $\mathcal L_{\mathrm{report}}$ is future-report token cross-entropy, and $\mathcal L_{\mathrm{finding}}$ is masked binary cross-entropy on future findings. We use $(\lambda_S,\lambda_R,\lambda_F)=(1,1,0.5)$. Every optimizer update sums the temporal loss and one current-task loss, with unit weight on the latter. Cycling through the four tasks implements the task average in \cref{eq:task_loss}. Spatial current-task batches include the auxiliary consistency term when enabled. Temporal prediction and reusable representation are evaluated separately on held-out patients.

\paragraph{Target updates and implementation choices.}
At model initialization, the target encoder copies the online encoder, including all trainable state-construction parameters. The target forward pass uses evaluation mode and stop-gradient. After every joint optimizer update, its parameters follow an exponential moving average:
\begin{equation}
    \bar\eta\leftarrow m\bar\eta+(1-m)\eta,\qquad m=0.99.
    \label{eq:target_ema}
\end{equation}
EMA covers all trainable state-encoder parameters, including LoRA, the JEPA adapter, slot queries, positional embeddings, and readouts; it excludes the predictor and task decoders. Immutable pretrained parameters remain frozen and can share storage, while target buffers are copied from the online encoder. Joint training uses AdamW with learning rates $5\times10^{-5}$ for LoRA and $10^{-4}$ for other trainable parameters, weight decay 0.01, and gradient clipping at norm 1. One optimizer is retained throughout the run. LoRA has rank 8 and scaling factor $16/8$, and is applied at the four selected language and vision depths. Distributed training synchronizes gradients across ranks before the optimizer and EMA updates.

\paragraph{Data separation.}
Current-task and temporal batches use fixed data manifests with a global patient-level holdout across current tasks and temporal pairs. Conflicting records are removed from lower-priority splits, preserving test over validation over training membership. Current-task supervision uses MIMIC-CXR reports and finding labels, fixed CXAS segmentation targets, and online $128\to512$ SR pairs; Montgomery supplies an external human-mask test set. Temporal inputs consist of source images and reports with signed actual time intervals. MIMIC-IV contributes the existing admission linkage, but laboratory results, medications, and vital signs are not model inputs. Evaluation predicts from source observations before accessing target references.
