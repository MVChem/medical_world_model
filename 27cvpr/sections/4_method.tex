\paragraph{Overview.}
\method{} couples a multimodal state encoder with a horizon-conditioned latent world model (\cref{fig:medworld_jepa_overview}). At both time points, four vision--language slots and four visual slots form the state. Task decoders jointly supervise its construction, with direct image input for segmentation and super-resolution. The world model predicts future slots from the current state and horizon while further adapting the state encoder. For forecasting, these predicted slots augment a native Qwen vision--language decoder that also reads the current radiograph, available report/history, and horizon. This revised architecture remains pending training and evaluation; the completed Table~\ref{tab:future_prediction} adaptations are legacy prototypes with a different readout.

\subsection{State Representation}
\label{sec:state_representation}

\paragraph{Shared multimodal state encoding.}
Current and follow-up observations share an encoding design with $K=8$ slots of width $d=1024$. We use image--report pairs for longitudinal prediction; image-based downstream evaluation withholds the same-exam report. State construction precedes both the task query and horizon. The two slot groups retain distinct feature sources throughout their readout and alignment.

\paragraph{Visual and vision--language feature sources.}
A frozen JEPA encoder $f_\theta$ provides spatial features~\citep{assran2023ijepa,bardes2024vjepa,murlabadia2026vjepa21}, mapped by a trainable visual adapter $a_\rho$ into the VLM embedding space of width $d_L$:
\begin{equation}
    \begin{aligned}
        D_\tau&=f_\theta(X_\tau)\in\mathbb R^{N_D\times d_D},\\
        V_\tau&=a_\rho(D_\tau)\in\mathbb R^{N_V\times d_L}.
    \end{aligned}
    \label{eq:visual_evidence}
\end{equation}
The VLM fuses $V_\tau$ with available text embeddings, yielding layerwise hidden states $H_\tau^{(\ell)}$. In parallel, the VLM's own vision encoder processes $X_\tau$ to produce visual features $F_\tau^{(k)}$ before language fusion. These native visual features supply the last four slots; the JEPA-to-VLM adapter and the slot readouts below have separate roles.

\paragraph{Multi-scale slot construction.}
As shown in Figure~\ref{fig:task_supervised_slots}, we select four depths from each source: one early layer, two intermediate layers, and the final layer. Let $\ell_j$ and $k_j$, $j=1,\ldots,4$, index the selected fusion and visual layers. Multi-scale refers to this hierarchy of representation depths. The lightweight adapter aggregates each selected feature sequence and projects it to one $d$-dimensional slot using source-specific learned readouts $r_j^{\mathrm{f}}$ and $r_j^{\mathrm{v}}$:
\begin{equation}
    \begin{aligned}
        s_{\tau,j}^{\mathrm{f}}&=r_j^{\mathrm{f}}(H_\tau^{(\ell_j)})\in\mathbb R^d,\\
        s_{\tau,j}^{\mathrm{v}}&=r_j^{\mathrm{v}}(F_\tau^{(k_j)})\in\mathbb R^d,\\
        S_\tau&=E_\eta(O_\tau)=[S_\tau^{\mathrm{f}};S_\tau^{\mathrm{v}}]
        \in\mathbb R^{8\times d}.
    \end{aligned}
    \label{eq:vlm_state}
\end{equation}
Each group stacks its four slots in depth order: $S_\tau^{\mathrm{f}}=S_{\tau,1:4}$ and $S_\tau^{\mathrm{v}}=S_{\tau,5:8}$. Alignment gives them a common width while preserving their sources; visual readouts do not receive fused or report features. Slots vary with the observation, with no fixed assignment to diseases, organs, or image regions. All eight enter the world model without further pooling. The encoder parameters $\eta$ comprise the adapters, slot readouts, and selected VLM parameters.

\paragraph{Task-conditioned readout.}
Each task uses a decoder with parameters $\omega_q$ and, when needed, a query $Q_q$. Classification and instruction-based disease recognition read all eight slots; the latter also receives a question and generates a disease list. Segmentation reads the input image together with only the four visual slots:
\begin{equation}
    \widehat M_\tau=H_{\omega_{\mathrm{seg}}}(X_\tau,S_\tau^{\mathrm{v}},Q_{\mathrm{seg}}).
    \label{eq:segmentation_interface}
\end{equation}
Image-guided feature upsampling motivates this combination: FeatUp's guided variant~\citep{fu2024featup} lifts coarse backbone features to higher spatial resolution using image detail and multi-view consistency, while UPLiFT~\citep{walmer2026uplift} combines image guidance with local feature aggregation and multi-scale reconstruction supervision. We use this complementarity through hidden-state conditioning: the image branch retains spatially resolved local evidence, and $S_\tau^{\mathrm{v}}$ supplies visual context from multiple depths as the decoder constructs dense outputs. Task losses learn their interaction without imposing a one-to-one slot-to-pixel correspondence or a separate feature-matching objective.

Super-resolution likewise reads image pixels and four visual slots, both derived exclusively from the same low-resolution input:
\begin{equation}
    \begin{aligned}
        \widehat X^{\mathrm{HR}}&=H_{\omega_{\mathrm{SR}}}(X^{\mathrm{LR}},S^{\mathrm{v,LR}}),\\
        \mathcal L_{\mathrm{SR}}
        &=\frac{1}{N}\left\|\widehat X^{\mathrm{HR}}-X^{\mathrm{HR}}\right\|_F^2.
    \end{aligned}
    \label{eq:sr_loss}
\end{equation}
Here $S^{\mathrm{v,LR}}$ is obtained by applying the visual encoder and its four readouts to $X^{\mathrm{LR}}$. The HR image supplies supervision only. $N$ counts valid target pixels, excluding padding; prediction and target share an intensity scale. Neither spatial decoder reads $S^{\mathrm{f}}$. The expanded six-task evaluation adds standard VQA, report generation, and phrase grounding through the adaptation protocol.

\subsection{State Prediction}
\label{sec:state_prediction}

\paragraph{Horizon-conditioned latent dynamics.}
The latent world model takes the current state tokens and an embedding of the requested horizon, and predicts a state with the same token shape:
\begin{equation}
    \widehat S_{t,h}=P_\psi(S_t,h)\in\mathbb R^{K\times d}.
    \label{eq:state_transition}
\end{equation}
The predictor receives both slot groups, with no additional image or feature-map input. Latent prediction on pretrained features has precedent in DINO-WM~\citep{zhou2025dinowm}; our predictive space combines fusion and visual slots. Prediction is direct at $h$; multi-time-point records supply training pairs without requiring autoregressive rollout.

\paragraph{Observed future states as targets.}
Let $E_{\bar\eta}$ denote the target instance of the same encoding design. The actual follow-up provides the target for latent prediction:
\begin{equation}
    \begin{aligned}
        S^*_{t^+}&=E_{\bar\eta}(O_{t^+})\in\mathbb R^{K\times d},\\
        \mathcal L_{\mathrm{future}}
        &=\ell_S\!\left(\widehat S_{t,h},\operatorname{sg}(S^*_{t^+})\right),
    \end{aligned}
    \label{eq:future_latent_loss}
\end{equation}
where $\operatorname{sg}$ stops target-branch gradients. The follow-up image supplies both feature pathways, and its report contributes to the fusion slots. This latent objective supervises the eight future slots, with no separate dense feature-map loss. Future observations and their modality indicators are not predictor inputs.

The fixed source and depth ordering establishes correspondence between predicted and target slots. The latent distance and normalization remain to be selected; elementwise mean squared distance is one candidate. Current spatial decoders also require the corresponding input image and therefore do not directly define dense future outputs.

\paragraph{Native report forecasting with predicted-state context.}
Let $A_\gamma$ project the eight predicted slots to the native Qwen language width. The forecast decoder retains Qwen's native vision encoder and image--text interface:
\begin{equation}
    (\widehat R_{t,h},\widehat p_{t,h})
    =D_\omega\!\left(X_t,C_t,h;A_\gamma(\widehat S_{t,h})\right).
    \label{eq:augmented_forecast}
\end{equation}
Here $C_t$ includes the current report and source-available clinical history. Native visual tokens from $X_t$, the current text, and the horizon remain in the decoder context; projected future slots are inserted at the end of the native user message, before the assistant generation prompt. The finding head reads the final source-prompt hidden state before any teacher-forced future report tokens. Both native supervised fine-tuning and the state-augmented condition use the same aspect-preserving 512-pixel source image, native decoder/finding-head initialization, and report objective. Encoder and decoder share immutable pretrained weights but have independent LoRA parameters. Follow-up images never enter this context; follow-up report tokens are used only as causally masked training targets.

The native supervised baseline omits $A_\gamma(\widehat S_{t,h})$. Its comparison with \method{} measures the contribution of the added state branch, which includes a JEPA encoder and learned dynamics. Isolating prediction and compression further requires controls that retain the same encoders and supply current slots or full tokens. In the shuffled control, only the state branch uses a different patient's source observation from the same split; the native decoder retains the true current image, text, and requested horizon.

\subsection{Two-Stage Training}
\label{sec:training}

Single-time-point annotations supervise state content; longitudinal pairs supervise its evolution. Related staged VLM/world-model adaptation appears in VLA-JEPA~\citep{sun2026vlajepa}. We first establish a task-supervised medical state space and then learn longitudinal dynamics within it.

\paragraph{Stage 1: task-supervised state pretraining.}
Starting from pretrained JEPA and VLM weights, we jointly train the adapters, multi-scale slot readouts, task decoders, and selected VLM parameters using parameter-efficient adaptation~\citep{hu2022lora}; JEPA remains frozen. For the tasks $\mathcal Q_i$ supported by sample $i$, we minimize
\begin{equation}
    \mathcal L_{\mathrm{task}}
    =\mathbb E_i\!\left[
        \sum_{q\in\mathcal Q_i}\alpha_q\,
        \ell_q\!\left(\widehat y_i^{(q)},y_i^{(q)}\right)
      \right],
    \label{eq:task_loss}
\end{equation}
where each prediction uses the task-specific slot subset and inputs defined above. Classification uses binary cross-entropy, report generation and disease recognition use token cross-entropy, segmentation uses Dice and pixel cross-entropy, and SR uses \cref{eq:sr_loss}.

There is no stop-gradient between the task decoders and slot readouts. Task gradients flow through $S$ into the learned aggregation/projection modules and any adapted source layers, jointly with decoder updates. Classification and disease recognition supervise both slot groups; segmentation and SR directly supervise $S^{\mathrm{v}}$ and their image decoders. Thus training updates the shared parameters that produce observation-dependent slots, rather than treating each sample's slots as independent optimization variables.

\paragraph{Stage 2: future state prediction fine-tuning.}
We initialize the encoder from a newly trained $4+4$ Stage~1 model and train $P_\psi$ on same-patient current--future observations, primarily MIMIC-CXR image--report pairs~\citep{johnson2019mimiccxr}. The legacy final-language-layer checkpoint does not initialize this state design. Future latent, report, and finding losses update $P_\psi$ and the current-state construction modules, while the latter two also train the native forecast decoder; JEPA remains frozen. With optional current-task replay,
\begin{equation}
    \begin{aligned}
    \mathcal L_{\mathrm{stage2}}
    ={}&\lambda_S\mathcal L_{\mathrm{future}}
       +\lambda_R\mathcal L_{\mathrm{report}}\\
      &+\lambda_F\mathcal L_{\mathrm{finding}}
       +\beta\mathcal L_{\mathrm{task}},
    \end{aligned}
    \label{eq:joint_loss}
\end{equation}
where losses are averaged over sampled training pairs, $\mathcal L_{\mathrm{report}}$ is future-report token cross-entropy, and $\mathcal L_{\mathrm{finding}}$ is masked binary cross-entropy on future findings. Setting $\beta=0$ omits current-task replay. The native supervised baseline uses the same report and finding losses, without a latent target. Temporal prediction and reusable representation are evaluated separately on held-out patients.

\paragraph{Target updates and implementation choices.}
The target encoder is a frozen snapshot of the new $4+4$ Stage~1 encoder; its parameters remain fixed throughout Stage~2. Its immutable pretrained weights can share storage with the online branches, while its copied adapters and readouts remain separate and receive no updates. Stop-gradient excludes the target pass from future-loss backpropagation. The initial implementation uses classification and current-report state supervision together with native current-report decoder training in Stage~1; this subset is not the complete six-task protocol. \pending{validate the revised native decoder, selected layer/readout configuration, and matched training budgets before reporting new results; see the supplementary material}.
