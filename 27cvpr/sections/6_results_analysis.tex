\subsection{Future-State Prediction}

We evaluate whether predicted patient states support clinically meaningful forecasts across five tasks: future clinical VQA, disease progression prediction, report generation, mortality prediction, and remaining length-of-stay estimation. Given a source examination and its available report, MedWorld-JEPA predicts latent states at specified horizons, which are interpreted through task-specific readouts. All forecasts use information available at the source time, with subsequent examinations and clinical outcomes providing evaluation targets.

For future clinical VQA, the model answers questions about findings in a subsequent examination. We use questions with categorical answers and report accuracy after answer normalization. Disease progression prediction assesses whether individual findings improve, remain stable, or worsen between the source and target examinations. We report balanced accuracy to account for differences in class frequency. For future report generation, we decode the predicted state into a report and evaluate its agreement with the observed follow-up report using RadGraph F1, which measures the correspondence of extracted clinical entities and relations. The prediction horizon for these tasks is the elapsed time between examinations.

We further assess clinical outcomes using linked MIMIC-IV records. Mortality prediction estimates the risk of death within 30 days of the source examination and is evaluated using AUROC. Remaining length-of-stay estimation predicts the time from the source examination to the end of the corresponding hospitalization, measured by mean absolute error in days. Outcome evaluation includes eligible patients regardless of whether they undergo subsequent imaging. We additionally compare current-state-only readouts with those using predicted states to assess the contribution of temporal prediction.

\subsection{Downstream Task Evaluation}

We evaluate the utility of learned state slots for image classification, visual question answering (VQA), and segmentation. The baseline uses image features with task-specific decoders. We augment this baseline with auxiliary features from DINOv2, RAD-DINO, and X-WIN, or with our learned state slots. These variants share the same task-decoder architectures, training splits, and number of optimization steps. We additionally evaluate Qwen3.5-9B through zero-shot prompting for classification and VQA.

\Cref{tab:downstream_tasks} compares performance across the three tasks. Classification is evaluated using macro-averaged AUROC (AUC) and average precision (AP). For VQA, we report exact match (EM) and micro-averaged F1 ($\mu$F1). Segmentation is evaluated using Dice and intersection over union (IoU). All tasks concern the current examination, with the question provided as an additional input for VQA.

\subsection{Patient trajectory}
\label{sec:patient_trajectory}

\Cref{fig:candidate_longitudinal_forecasting} reserves a longitudinal case study
with four to five observations from one test patient. The planned analysis
predicts each follow-up independently from the same Day~0 radiograph and report,
conditioned on the actual elapsed time. Observed follow-up images and reports
provide references only. Predicted reports and finding probabilities will be
compared with Copy Current and a matched forecaster at the irregular observation
times. This is fixed-origin, multi-horizon forecasting; connecting the predictions
does not constitute an autoregressive rollout. Case selection and predictions
remain pending.

\subsection{Attention visualization}
\label{sec:attention_visualization}

\Cref{fig:candidate_slot_attention} reserves a view of how the four visual slots
aggregate patches from the current radiograph. The planned visualization uses
the actual softmax weights of the learned visual-slot readout at each selected
encoder depth, with a shared color scale. These weights describe current-state
construction; the accompanying report text supplies case context, not a
finding-specific attention query. Slots have no prescribed anatomical roles,
and the maps do not establish future lesion locations or forecasting accuracy.
Weight export and verification of the token-to-image mapping remain pending.
