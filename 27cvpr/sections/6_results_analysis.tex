\subsection{Future prediction}

\Cref{tab:future_prediction} reserves four dimensions of clinical forecasting:
future finding AP/AUROC, progression Transition/Direction F1, report
RadGraph/GREEN, and probability Brier/ECE. The held-out cohort contains 297
pairs from 94 patients. Clinical forecast readouts and their evaluation for the
current model remain pending; the latent prediction objective alone does not
supply these scores. Direction labels also require review. We therefore make
no quantitative forecasting claim for the current implementation.

\subsection{Downstream tasks}

\Cref{tab:downstream_tasks} covers classification, VQA, and segmentation,
without invoking the future predictor at inference. All tasks use image-only
observations; VQA additionally supplies the question to its readout. The shared
task decoder always receives native image tokens, with all eight slots added
in \method{} and omitted in the independently trained no-slots control.

Classification reports macro AUROC and non-interpolated AP over supported
labels among 13 MIMIC finding/device categories, with uncertain and missing
labels masked. The 353-image test set supports both classes for 11 labels.
Native checkpoints use Yes/No answer likelihoods; adapted models use a
supervised classification head. VQA samples 100 Verify, 100 Choose, and 100
Query questions from the official MIMIC-CXR-VQA test split using seed 42,
covering 225 distinct images. We report exact answer-set match (EM) and micro
F1 under the same JSON parsing and answer vocabulary for all models.
This is a fixed subset protocol, not a full-benchmark result.

Among the evaluated native checkpoints, MedGemma-1.5-4B reaches the highest
classification AUROC/AP (71.54/85.30), while Qwen3.5-4B reaches the highest
VQA EM/micro F1 (42.33/42.25). Strict parsing yields 52, 40, 147, and 206
invalid answers for Qwen3.5-0.8B, 4B, 9B, and MedGemma, respectively.
These scores reflect both answer content and compliance with the output
format; they do not establish a general ordering of model capabilities.

Segmentation will report Dice against CXAS pseudo-labels for the two lungs
and heart on 447 test images, and human lung Dice on 138 Montgomery images.
Pseudo-label agreement and external human-mask performance are separate
endpoints. Final segmentation testing is not enabled in the current paired
run, so neither trained row has a segmentation score yet. The matched
with/without-slots comparison also remains pending for classification and VQA.
Gains over native zero-shot checkpoints would measure the entire adapted
system; isolating slot conditioning requires the matched control, and assessing
its value beyond task adaptation additionally requires native Qwen fine-tuning.

\subsection{Patient trajectory}
\label{sec:patient_trajectory}

\Cref{fig:candidate_longitudinal_forecasting} reserves a longitudinal case study
with four to five observations from one test patient. The planned analysis
predicts each follow-up independently from the same Day~0 radiograph and report,
conditioned on the actual elapsed time. Observed follow-up images and reports
provide references only. Predicted reports and finding probabilities will be
compared with Copy Current and a matched forecaster at the irregular observation
times. This is fixed-origin, multi-horizon forecasting; connecting the predictions
does not constitute an autoregressive rollout. Case selection and predictions
remain pending.

\subsection{Attention visualization}
\label{sec:attention_visualization}

\Cref{fig:candidate_slot_attention} reserves a view of how the four visual slots
aggregate patches from the current radiograph. The planned visualization uses
the actual softmax weights of the learned visual-slot readout at each selected
encoder depth, with a shared color scale. These weights describe current-state
construction; the accompanying report text supplies case context, not a
finding-specific attention query. Slots have no prescribed anatomical roles,
and the maps do not establish future lesion locations or forecasting accuracy.
Weight export and verification of the token-to-image mapping remain pending.
