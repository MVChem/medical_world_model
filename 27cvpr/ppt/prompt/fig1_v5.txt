CENTRAL MESSAGE
MedWorld-JEPA builds a multimodal state space and learns future state transitions in that space. Show two complete, corresponding encoding branches: current image + current report, and observed future image + future report. Both use the same multimodal encoding design: V-JEPA image features connect through a visual adapter to a VLM; report tokens enter that VLM separately. Each branch produces a state containing BOTH dense JEPA features D and contextualized VLM state tokens S. The current state feeds a task decoder and a Latent World Model. The world model predicts a future latent state, supervised by the state encoded from real follow-up observations.

The current and future branches make shared state encoding explicit. They are separate forward passes at two observation times, not forward and backward temporal prediction. The only temporal prediction direction is current -> future. The future branch supplies a training target, never an input to the current branch or the predictor.
