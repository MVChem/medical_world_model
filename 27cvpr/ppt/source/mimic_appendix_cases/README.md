# MIMIC appendix resources

Attach the six JPG files in this folder together with
`../../prompt/medworld_jepa_mimic_appendix_gpt_image2_prompt.txt` when asking
Image 2 to create the appendix figure.

The files are organized as three paired trajectories:

- Case A: clear change over 20.1 hours (`0–24 h`)
- Case B: stable follow-up over approximately 24.0 hours (`0–24 h`)
- Case C: clear change over 50.5 hours (`24–72 h`)

`appendix_cases.csv` and `curated_pairs.json` are local fact references for the
case metadata; the six JPGs are the intended image attachments.

These are restricted MIMIC-derived data. Keep them in an approved environment
and handle any upload or sharing in accordance with the applicable MIMIC data
use agreement. Retrospective MIMIC-IV events are audit context, not model input
and not evidence of a causal treatment effect.
