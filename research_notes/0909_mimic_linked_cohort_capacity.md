# CXR + 临床数据库：全量可连接规模与示例

日期：2026-09-09。用户明确要求：后续数据必须连接影像与临床数据库，先核验数据，不训练。

**本次核实的对应关系是 MIMIC-CXR + MIMIC-IV 3.1。** `MIMIC_example` 的四个原始例子全部连接到唯一同次住院，十例扩展集有八例成功、两例无共同住院。当前 appendix 图使用的科室和连续随访信息来自这套 IV 连接。III 在本地存在，但不是这些例子的临床来源。

MIMIC-IV 与 III 的标识符经过重新生成，不能按同名 `subject_id` 互连；CXR 可以按共享患者标识符和一致的去标识化时间线连接 IV。[原始论文](https://www.nature.com/articles/s41597-022-01899-x)、[IV 官方连接说明](https://physionet.org/content/mimiciv/3.1/)

## 1. 本地全量统计，已完成

没有沿用 pilot 的 12,000 / 1,000 数量上限。扫描本地全部 CXR 元数据、图像/报告可用性与 IV 3.1 的 patients、admissions、icustays。

共同规则：同患者完整时间线中相邻两个 study；同 AP/PA；采集时间不重叠；间隔 6 小时至 30 天；图像文件存在；两端报告有 Findings 或 Impression；官方标签记录存在，但不按未来标签值挑选；沿用官方患者互斥 split。

“同住院”在主表中包括该次入院前急诊，即两次片子的时间分别唯一落在同一个 `[min(edregtime, admittime), dischtime]`。存在歧义时排除，不猜测对应住院。

| 纳入条件 | 配对数 | 患者数 |
|---|---:|---:|
| CXR 相邻、同视角候选，尚未核验报告分节 | 80,091 | 18,012 |
| 两端图像、Findings/Impression 可用 | 70,318 | 17,145 |
| 上述患者还能在本地 IV patients 找到 | 66,706 | 16,273 |
| **进一步要求同次住院，6 小时–30 天** | **54,432** | **12,739** |
| 同次住院，6 小时–7 天 | 52,690 | 12,479 |
| **同次住院，6–72 小时** | **46,715** | **11,468** |
| 上一行＋检查类型和体位两端已知且一致 | **25,931** | **8,454** |
| 同次住院且同一 ICU stay，6–72 小时 | 27,019 | 5,777 |
| 上一行＋检查类型和体位两端已知且一致 | 15,031 | 4,582 |

这些行有交集或包含关系，不能相加。同 ICU 是同住院的子集。检查类型/体位严格条件指字段非空且相同，并不能保证所有采集参数一致。

若排除急诊扩展、只接受严格 `[admittime, dischtime]`，6 小时–30 天的同住院规模为 **47,192 对、10,397 位患者**。定义不同应单列，不与含急诊主表混用。

本地 CXR 共 65,379 位患者，其中 61,868 位能在本地 IV 3.1 patients 表找到，3,511 位不能。没有把所有 CXR 患者都默认为已成功连接；未覆盖的具体原因尚未逐一核验。

66,706 对患者级成功连接的数据里，54,432 对唯一同住院、5,934 对各自唯一连接到不同住院、2,175 对两端均无住院匹配、4,144 对一端无匹配、21 对存在端点住院歧义。患者级连上不等于纵向 pair 属于同次住院。

## 3. “有效”目前证明到哪一步

已证明：图像和报告存在、纵向时间/视角关系满足上述规则、同一患者的两端都能唯一连接到 IV 的同一临床就诊窗口。

尚未证明：每对都有充足的预测时点前生命体征、化验、给药、呼吸支持记录；记录是否已在当前时点入库；当前报告是否已可用；标签是否准确；体位缺失能否可靠补全；图像近重复及实际干预的影响。因此这些数字是**结构上合格的连接规模**，不是已经逐例审核、所有临床输入齐全的最终训练样本数。

建议用 46,715 对同住院短期数据作为审计母集，保留采集信息缺失类别；25,931 对作为采集条件更明确的对照子集。是否把严格子集作为主训练集，要看人工核验及临床字段覆盖。不能只因元数据缺失就断言该病例更差，也不能把所有稳定随访删掉。

下一版数据的临床连接是必需条件。预期组织为：

```text
当前 CXR + 当前报告 + 截至当前已记录的临床历史 + 请求预测时间
    → 未来 CXR / 报告 / 可判断疾病状态
```

患者/住院/ICU ID 用于连接与审计。真实区间用药、置管等信息另存为回顾性核验字段；不能直接加入普通当前时点预测的输入。若研究给定未来行动的预测，应另外定义行动条件与评价方案。

**旧 pilot 没有接入临床数据。** 本次没有改写其缓存、重算正式主表或启动新训练。后续重建数据集应使用新的版本目录并保留原始 cohort 作为对照。

## 4. 六组真实示例，已整理

[打开独立 HTML 示例页](../results/mimic_linked_examples_20260909/index.html)（约 26.7 MiB，原始 JPG 已嵌入）；[原始结构化示例 JSON](../results/mimic_linked_examples_20260909/examples.json)；[前三组图像预览](../results/mimic_linked_examples_20260909/preview.png)。

每组都包含两张真实片、两份报告、六疾病弱标签、检查类型/体位以及临床连接。A–D 复用既有 appendix 示例库；E–F 从实际 pilot 训练缓存中，按确定性顺序取首个满足对应住院/采集条件的例子，不根据模型表现挑选。

| 示例 | 间隔 | 需要核验的问题 |
|---|---:|---|
| A：同次 SICU，报告描述明显变化 | 20.1 小时 | 无明确肺水肿 → 肺水肿/积液；有通气/用药记录，当前体位元数据缺失 |
| B：稳定随访 | 24.0 小时 | 积液/肺不张持续，仍有 Furosemide 等记录；稳定不等于无治疗 |
| C：置管相关随访 | 9.2 小时 | 未来报告明确已放置 pigtail；气胸 uncertain → present 不等于新发 |
| D：判断受遮挡影响 | 27.6 小时 | 气胸 present → uncertain 不能标为消失；当前报告自身增减措辞不一致 |
| E：同患者、跨住院 | 28.6 天 | 两端有各自的 IV 记录，但不是同一次住院；原 pilot 中真实存在 |
| F：同 AP、体位改变 | 24.9 小时 | Recumbent → Erect；报告也描述装置/肺部变化，不能把影像变化全归于体位 |

这些是围绕具体问题挑选的讨论示例，不是随机噪声率估计，也没有新增临床判读。HTML 展开项保留原文，中文说明按报告/元数据整理。
