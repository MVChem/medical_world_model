# Longitudinal pair 数据审计与后续计划

日期：2026-09-09。对应实验：`pilot_20260908_8h`。本文补充[此前的实验讨论](0909_experiment_review_and_plan.md)。

随后用户明确要求下一版数据必须连接临床数据库。已补充[全量 CXR + IV 可连接规模与六组真实示例](0909_mimic_linked_cohort_capacity.md)：同住院短期 46,715 对，采集字段严格一致子集 25,931 对；均尚未用于新训练。

本次只读取现有缓存、元数据、MIMIC-IV 住院/ICU 表及保存的预测，运行 CPU 统计。没有训练、GPU 模型推理、修改 cohort、修改 decoder，原结果表保持不变。

**结论：任务构造的异质性和监督稀疏有实际证据，应先于新训练解决或量化。但现有结果不能把模板化全部归因于数据，也不能据此判定 8 个 slots 无用。** 时间跨度、AP/PA、未知标签已有部分控制；住院边界、采集细节和患者权重没有充分控制。

## 1. 当前究竟在配对什么

这轮训练是 **MIMIC-CXR 内部的影像—报告纵向配对**，没有把 MIMIC-III 或 MIMIC-IV 临床记录作为训练输入。

实际路径：

1. 从 CXR metadata 建立同一 `subject_id` 的完整 study 时间线；按时间排序，只考虑相邻两个 study。中间有不符合视角要求的检查，也不会跳过去找更远的“合适未来”。
2. 两个 study 必须能各选出一张相同视角的正位片：AP→AP 或 PA→PA；同时存在时优先 PA。同 study 同 view 有多图时按像素面积、DICOM ID 确定性选一张，报告和弱标签仍是 study 级。
3. 排除歧义时间戳、采集窗口重叠、缺失图像/报告/标签记录、split 不一致。实际选中两张图的间隔须在 **6 小时到 30 天**。
4. 沿用官方 split，并验证 train/validate/test 患者互斥。split 内按 patient/source/target 与 seed 的哈希排列，截取至上限；训练取 12,000 对，验证实际 645 对，测试 1,000 对。
5. 未按疾病变化筛选；没有每患者/每住院的配对上限。Stage 2 按 pair 均匀抽样，而非按患者均匀抽样。
6. 当前输入为当前图像、当前报告的 Findings/Impression，以及时间档位。精确间隔保存在缓存，但模型只看到四档 horizon。没有结构化 EHR、住院 ID、ICU stay ID 或区间干预输入；当前报告可能已含装置或治疗相关描述。

相关实现：[prepare.py](../code/medworld_table1/prepare.py)、[相邻检查筛选](../code/MIMIC_example/build_mimic_transitions.py)、[训练采样](../code/medworld_table1/data.py)。本次确认 prepare/data/metrics 与 run 内归档源码一致。

| 时间间隔 | 训练：12,000 对 | 测试：1,000 对 |
|---|---:|---:|
| 6–24 小时 | 4,843（40.4%） | 337（33.7%） |
| >24–72 小时 | 3,786（31.6%） | 289（28.9%） |
| >72 小时–7 天 | 1,468（12.2%） | 136（13.6%） |
| >7–30 天 | 1,903（15.9%） | 238（23.8%） |

训练间隔中位数 27.2 小时，测试为 39.9 小时。测试的长间隔比例更高。不是没有时间条件的任意跨度混合，但 7–30 天这一档仍很宽，也混入了不同就诊过程。

## 2. MIMIC-III、IV 与 CXR 的关系

本地都有 III 和 IV，但“文件存在”不等于已接入训练。CXR 可按 `subject_id` 连接 **MIMIC-IV**，再利用一致的去标识化时间线确定对应住院/科室区间。[MIMIC-IV 官方连接说明](https://physionet.org/content/mimiciv/3.1/)

MIMIC-III 与 IV 的患者标识符不共用，不能按相同 `subject_id` 直接连接；因此不能把 III 当作 CXR 对应的临床侧数据库来直接 join。[MIMIC-IV 原始论文](https://www.nature.com/articles/s41597-022-01899-x)

仓库已有的 [link_mimic_iv_context.py](../code/MIMIC_example/link_mimic_iv_context.py) 用于少量展示和回顾性检查：同 patient，两个 CXR 时间均处于同一住院窗口，再找 ICU stay。其窗口从 `min(edregtime, admittime)` 到 `dischtime`，包括该次入院前急诊。**这个链接没有用于当前训练 cohort 的筛选或输入。**

## 3. 住院边界：已有量化证据

本次将完整现有 cohort 与本地 IV 3.1 admissions/icustays 做只读连接。下表采用上述“住院＋该次入院前急诊”窗口。

| 配对关系 | 训练 | 测试 |
|---|---:|---:|
| 两张片可连接到同一住院窗口 | 9,274 / 12,000（77.3%） | 692 / 1,000（69.2%） |
| 两端各自唯一连接，但对应不同 hadm_id | 1,010（8.4%） | 143（14.3%） |
| 一端无法连接 | 726（6.1%） | 89（8.9%） |
| 两端均无法连接 | 990（8.3%） | 76（7.6%） |
| 两张片处于同一 ICU stay | 4,810（40.1%） | 359（35.9%） |

未连接不等于配错：可能涉及未住院急诊、门诊、记录覆盖或窗口定义。本次没有用独立 ED stays 表进一步区分这些情况。同一 ICU stay 的比例也不能被解释为所有 ICU 相关样本的比例。

若只用严格 `[admittime, dischtime]`，同住院分别为 8,011 / 551 对，明确不同住院为 185 / 8 对；急诊片会更多落入“未连接”，所以不能混用两种分母和定义。

**7–30 天档的问题最突出：训练仅 311 / 1,903（16.3%）、测试仅 22 / 238（9.2%）能连到同一住院＋急诊窗口。** 测试该档有 121 对明确对应不同住院，其余 95 对无法完整连接。若我们的目标是单次住院内的短期状态演化，这一档与目标任务明显不一致；若目标是跨就诊随访预测，则需单独定义和评估，不能默认等同于 ICU 内的动力学。

## 4. 稳定样本、弱标签和患者相关性

训练使用官方 CheXpert 六疾病标签。未提及 `-2`、不确定 `-1` 不进入疾病 BCE；Transition F1 也只在当前和未来都明确为 0/1 的参考字段上判断 onset/resolution。**代码没有把“本次未提及”直接标成“消失”。** 官方标签说明亦区分未提及、明确阴性、阳性及不确定。[MIMIC-CXR-JPG 标签定义](https://physionet.org/content/mimic-cxr-jpg/2.0.0/)

| 现有训练数据统计：官方 CheXpert，六疾病 | 数量 |
|---|---:|
| 至少一个明确二值标签发生变化的 pair | 1,332 / 12,000（11.1%） |
| 至少一个共同可判断字段，且这些字段均未变化 | 5,109（42.6%） |
| 没有任何共同可判断字段 | 5,559（46.3%） |
| 在有共同可判断字段的 6,441 对中，未观察到变化 | 79.3% |
| 可用于未来疾病 BCE 的字段 | 22,786 / 72,000（31.6%） |
| 当前、未来都明确可判断的字段 | 10,687 / 72,000（14.8%） |
| 六个未来疾病字段全部无法判断的 pair | 2,567 / 12,000（21.4%） |

这里的“未观察到变化”不能称为临床稳定：可能只比较到了一个疾病，未记录的疾病仍可能变化。最后一行只是该 pair 的未来疾病头缺少有效标签，报告 CE 和 latent 监督仍然存在。

既有测试集 CheXbert 口径为：169 对观察到变化、586 对观察到未变化、245 对没有共同可判断字段；有共同字段者中未变化占 77.6%。不能把该统计与训练 CheXpert 口径混为一谈。

两种提取器的差异也已量化：测试未来 6,000 个字段中，官方 CheXpert 有 1,881 个二值可判断，评估 CheXbert 有 2,611 个。两者均可判断的 1,791 个字段里，有 33 个正负相反；另有 **820 个 CheXbert 可判断、CheXpert 未给二值标签**的字段。主要差异包括覆盖范围，不应把所有差异都称为错误标签，也不能默认任一提取器就是真实影像结论。

患者权重方面：训练 6,853 位患者，单患者最多 25 对；配对最多的约 10% 患者贡献 29.2% 的训练 pair。测试 195 位患者，最多 47 对；配对最多的约 10% 患者贡献 37.1% 的测试 pair。验证集单患者最多 74 / 645 对（11.5%），也值得注意。

没有重复 pair ID 或完全重复端点组合；但训练有 1,219 个 observation 同时作为某 pair 的未来和另一 pair 的当前，测试有 498 个。患者跨 split 泄漏已排除，**同患者链式相关性和贡献不均仍存在**。尚未检查像素哈希或近重复图像，不能声称已做图像去重。

训练目标报告有 11,888 种不同字符串 / 12,000 对，当前与未来报告完全相同仅 14 对。因此“疾病标签经常不变”不等于训练报告全部相同，不能单靠前者解释跨患者输出只剩少数模板。

## 5. 视角、体位与干预

AP→PA 已排除；本次逐对复核缓存和元数据，全部保持同 view。但匹配 AP/PA 没有匹配具体检查类型及体位。

| 两端元数据均已记录时的差异 | 训练 | 测试 |
|---|---:|---:|
| 检查类型字符串不同 | 1,366 / 11,366（12.0%） | 159 / 924（17.2%） |
| 检查类型中 PORTABLE 关键词一端有、一端没有 | 1,029 / 11,366（9.1%） | 115 / 924（12.4%） |
| 体位不同 | 979 / 8,661（11.3%） | 98 / 744（13.2%） |

体位至少一端缺失：训练 3,339 对，测试 256 对；检查类型至少一端缺失：634 / 76 对。PORTABLE 关键词缺失不能证明采用了标准固定设备；这只是可复现的元数据代理。

同一日内的 pair 为训练 1,212（10.1%）、测试 74（7.4%），仍满足至少 6 小时。仅凭短间隔或设备描写无法确认由插管、置管、手术引起；本次尚未核验实际干预事件。未来若连接 IV，应区分：当前时点前已发生且已记录的信息可作为输入；当前到未来之间实际发生的干预只供回顾性审计/分层，不能直接作为普通预测任务的输入。

没有区间干预信息时，合理目标是“现有信息条件下、实际诊疗过程中的未来分布”。不能把它直接解释成未治疗的疾病自然演化，或声称学到了行动条件下的因果效应。报告措辞、弱标签、采集因素、未观测治疗均可能增加条件不确定性；这仍是机制假设，需要后续控制实验区分。

## 6. 现成预测的事后分层：没有重新训练

为检查“只是配对太杂吗”，本次取以下较严格测试子集：同一住院＋入院前急诊窗口、6–72 小时、检查类型与体位两端均有值且相同。相同 AP/PA 已由原 cohort 保证。

该子集有 **309 对、102 位患者**；其中 53 对有观察到的二值变化、174 对无观察到变化、82 对无法判断。有共同标签者中未变化比例 76.7%，仍不是临床判定的稳定率。

| 方法 | 全测试 CheXbert F1 | 严格子集 CheXbert F1 | 严格子集 Finding AUPRC | 严格子集 Transition F1 |
|---|---:|---:|---:|---:|
| Copy Current | 0.5821 | 0.5762 | | 0.0000 |
| Qwen3.5-0.8B direct | 0.4177 | 0.4446 | 0.8016 | 0.2303 |
| Stage-1 State + Matched LWM | 0.5049 | 0.5331 | 0.6937 | 0.2777 |
| MedWorld-JEPA | 0.5482 | **0.6092** | 0.8139 | 0.2802 |

同住院窗口但不限时间/采集细节的 692 对上，Copy Current / MedWorld-JEPA 的 CheXbert F1 分别为 0.5959 / 0.5895。

这说明模型与 Copy Current 的相对表现会随 cohort 构成变化，数据诊断值得优先推进。**这不是“清洗后重新训练”的实验，也不能证明性能差距由某一种噪声造成。** 选择条件会改变病例构成、缺失模式、阳性率及任务难度；没有针对该子集计算新的置信区间。Transition F1 在严格子集只有 8 种有真实事件支持的类别，全测试为 11 种，不能直接把 0.1994→0.2802 解释成进步。CheXbert F1 各表均支持六疾病，但病例构成仍不同。

这批结果没有改变正式主表，没有重新构建 R@1 候选池。观察到的报告模板化问题也仍待解决，不能因为子集分数变好就认定 decoder 已足够好。

## 7. 先做什么：保持暂停训练

1. **定义任务范围。** 将同次住院短期预测与跨就诊长期随访分开。首个诊断 cohort 可暂定同住院、6–72 小时，再分别报告 6–24 与 24–72 小时；这是待讨论的任务定义，尚未替换正式数据。
2. **补全数据审计。** 对未连接 pair 查 ED/门诊覆盖，审查体位/portable 元数据缺失，做图像哈希及近重复检查；审计报告截断和“单张图对应多视角 study 报告”的影响。
3. **小规模人工核验。** 在训练/验证中预先按短/长间隔、同/跨住院、采集一致/变化、标签变化/缺失分层，抽约 100–200 对，检查实际影像变化、报告遗漏、提取器分歧和干预。记录噪声比例，不按模型成败挑选样本。
4. **先用保存结果比较。** 加入患者均衡评价、patient bootstrap、分疾病和变化组报告；保留自然分布测试。不要删除所有 stable pair 来提高指标；使用未来标签的变化分层只是诊断，不能被包装成输入时即可选出的临床人群。
5. **讨论通过后再设计训练对照。** 固定模型、decoder 初始化、患者划分和更新预算，对比原 pair 与任务范围明确的 pair；患者均衡采样、标签口径、horizon 设计分别改动。数据因素与 decoder/state 消融应分别比较，避免一次同时换数据和 decoder 后无法归因。

后续报告生成诊断仍保留：真实未来 state → decoder 的上限、当前/预测/真实未来 state 的统一 decoder 对比、slots 打乱/置零及冻结线性读出。数据质量审计与模块诊断互相补充，现有证据不能省掉其中之一。
