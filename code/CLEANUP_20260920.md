## Retained dependencies

Only assets still consumed by MedWorld were transferred to
`/home/data2/chk/data/medworld`, exposed through the ignored `code/data/medworld`
symlink. These include current and temporal cohort manifests, classification
labels and splits, CXAS segmentation supervision, Montgomery images/masks,
benchmark reference manifests, and the local Qwen3.5-0.8B checkpoint directory.
They are not committed. Original MIMIC/VQA data and shared model caches were
not removed.

MedWorld defaults now use this shared asset root. `medworld/asset_paths.py`
translates historical configurations and Montgomery manifest paths and preserves
historical logical provenance keys. Frozen manifests retain their original bytes;
relocation does not change the dataset fingerprint or sample selection.

Native evaluation now owns its checkpoint inventory in
`medworld_zero_shot_eval/models.py` and its vLLM compatibility adapter in
`medworld_zero_shot_eval/startup/`. It no longer imports removed packages.
`prepare` snapshots the adapter with the rest of its own source.

The running `native_serial_vqa300_20260920` sweep is preserved. Its frozen config
is accepted through the asset translation; no worker restart or run-config edit
is required. Atlas has its own CXR/IV linkage and does not require the removed
`mimic_cxr_iv_linked` package.
