01 / UCSF

UCSF-ALPTDG

298 位患者、596 次 MRI。影像已解压并逐文件通过 CRC 校验。完整 HTML 按需加载由原始 NIfTI 生成的全体积显示缓存，原始影像保持不变。

  • 四序列：T1、T1 CE、T2、FLAIR。
  • 分割值 1 / 2 / 3 / 4：NCR、SNFH、ET、RC；体积使用体素计数 × 仿射矩阵体素体积 ÷ 1000，单位 mL。
  • 各扫描按正值强度的第 1–99.5 百分位独立设置显示窗；亮度不可用于定量比较。默认切片只根据首次分割中的非切除腔区域选择。
  • 原始发布版本配准到第二次扫描，当前界面用于回顾性探索；不能据此声称完全前瞻的预测验证。
  • 许可：非商业使用及 UCSF 数据使用协议。

02 / MU

MU-Glioma-Post

203 位患者，596 个影像时间点。影像由 Hugging Face 公开镜像下载； 所有文件名与字节数已和 TCIA 在线目录核对一致。

  • 临床表：597 个数值型 MRI 时间项，395 个候选相邻时间对。
  • 扫描仪表：654 行；官方影像摘要：596 个时间点。三个数字口径不同。
  • 临床时间与影像按原始编号匹配；缺失时间、缺失影像分别记录。
  • 596 组四序列 MRI，594 份分割 mask；缺标注不等于零体积。
  • 逐文件校验镜像 SHA-256 与 gzip CRC；此校验不等于取得官方文件哈希。
  • 体积表没有统一时间点 ID，不按行顺序生成纵向轨迹。
  • 许可：CC BY 4.0。
