# Data

## Recommended manual v2 protocol

Select [`medworld_0922.json`](../configs/medworld_0922.json) for new runs.
`prepared.py` reads the `medworld-prepared-v2` manifests generated by
[`mimic_atlas/data_processing`](../../mimic_atlas/data_processing/README.md) under
`code/data/medworld_0922`. Source images and masks are symbolic links to the
central data store. The adapter decodes originals on demand and writes no pixel
or feature caches. New training and evaluation use no CXAS pseudo masks.

The global segmentation layout has six channels:

| Dataset | Annotated cohort | Active channels | Role |
| --- | --- | --- | --- |
| MIMIC human CXR | 200 images | `0: lungs`, `1: heart` | Patient-disjoint train/validation/test |
| UCSF-ALPTDG | 596 MRI volumes | `2: NETC`, `3: SNFH`, `4: ET`, `5: RC` | Patient-disjoint train/validation/test |
| MU-Glioma-Post | 594 MRI volumes | `2: NETC`, `3: SNFH`, `4: ET`, `5: RC` | Patient-disjoint train/validation/test |
| Montgomery | 138 images | `0: lungs` | External `human_test` only |

MIMIC uses a union lung mask and a heart mask. Montgomery's two separate lung
masks are unioned into channel 0. MRI counts describe reviewed volumes; slices
from one volume are not independent annotations, and repeated visits from one
patient remain in one split.

Every segmentation example returns `targets` and `mask` with shape
`6 × 256 × 256`. The mask enables only the annotated channels inside the valid
image ROI. `segmentation_dataset`, `volume_id`, `active_channels`, and
`target_names` survive collation, so CXR and MRI can share a batch without treating
unannotated organs as negative labels. Classification retains its 13 four-state
CheXpert labels; uncertain and missing values are masked. VQA uses the official
image/question/answer records and the fixed answer vocabulary.

The v2 adapter checks manifest hashes, channel semantics, source paths, manual
annotation declarations and the six-channel model setting. It rejects CXAS kinds,
pseudo-label source declarations and legacy target arrays. Temporal files must
belong to the same prepared dataset and match its declared hashes. The six-channel
head cannot directly resume an old three-channel checkpoint.

## MRI decoding, sampling and evaluation

`mri_pixels.py` reads the original T1ce and reviewed mask volumes, checks matching
grids, and uses canonical RAS axial slices. Image-derived intensity windows are
independent of the target mask. Source images are padded to 512 square; supervision
and evaluation use 256-square grids. T1, T2 and FLAIR paths are retained in the
inventory, but current training inputs use only 2D T1ce slices. The decoder keeps
a bounded RAM cache and writes no volume copies.

`segmentation_sampling="balanced_dataset"` gives equal exposure to the training
datasets. Within each MRI dataset, a seeded permutation orders volume blocks and
shuffles slices within each block, reducing repeated gzip decompression. Dataset
selection and within-dataset ordering are reproducible from the seed and stream
offset across resume and distributed workers.

Evaluation sums slice-level intersection, predicted-positive and target-positive
counts on the 256 × 256 grids within each MRI `volume_id`, then computes IoU and
Dice. It averages over annotated channels and volumes within each dataset; a CXR
image is its own evaluation unit. Reports list each dataset separately and provide
an equal-weight dataset macro average for the evaluated split. New completed
experiments require classification/VQA plus MIMIC, UCSF, MU and external Montgomery
segmentation for both trained arms. Native Qwen segmentation is N/A.

## Shared boundaries and historical reproduction

`unified.py` enforces global patient holdouts across classification, segmentation,
VQA and temporal representation learning. Test/human-test take precedence over
validation, which takes precedence over training. It removes rows from conflicting
lower-priority splits and never moves them into evaluation. Counts, source hashes,
channel layout and sampling policy are saved in each run's `data_protocol.json`.

`temporal.py` supplies paired source/target observations and signed actual intervals
for auxiliary latent prediction. It is not a downstream classification or report
task. No current report or reference answer enters a downstream image
representation; VQA receives its question in addition to the image.

`current.py`, `medworld-prepared-v1`, and configurations with empty `prepared_data`
retain the historical interfaces for reproducing frozen old runs, including their
original CXAS protocol where applicable. Those three-channel configurations and
the historical 9B experiment are not templates for new manual-only training.
